# 优化播放页视觉与切歌体验

## Goal

让播放页的背景色与封面主体视觉一致，修正电视端按钮和播放队列中的中文垂直对齐，并消除返回歌单/歌手页面及切换歌曲时可见的空白闪烁。

## Background

- 用户实拍中，粉紫主体封面生成了大面积偏紫背景，蓝紫主体封面生成了偏黄绿色背景；当前实现只抽样 9 x 9 像素，并选择出现次数最多的 4-bit RGB 桶。低饱和大面积区域会压过主体色，接近灰色的结果还会退化为由歌曲标题和歌手哈希出的随机色（`AuthenticatedApp.kt:1728-1731`, `AuthenticatedApp.kt:3042-3105`）。
- 网易云音乐 TV 的私有取色实现没有公开，不能把外观推断表述为源码事实。Android 官方 Palette API 会综合颜色的饱和度、明度和像素占比生成多个色彩档案，适合作为本项目的可验证实现依据。
- “退出漫游”按钮直接在固定高度 TV Material `Button` 中渲染文本；播放队列行也依赖按钮内部内容布局和不对称的字体度量，没有显式的满高居中容器（`AuthenticatedApp.kt:2580-2619`, `AuthenticatedApp.kt:2839-2865`）。
- 首页歌单、全部歌单和“我的音乐”中的歌手/专辑使用 Composable 局部空列表，重新进入时会先显示空内容再请求网络。项目已有会话级 `LibraryRetainedStateStore`，但这些入口尚未复用（`AuthenticatedApp.kt:504-548`, `AuthenticatedApp.kt:682-749`, `AuthenticatedApp.kt:849-868`）。
- 新歌曲身份到达时，展示投影立即变为三个 `Loading`，封面解码状态同时清为 `null`，UI 因此短暂显示占位封面和“歌词加载中”（`AuthenticatedApp.kt:1589-1608`, `AuthenticatedApp.kt:1638-1671`, `NowPlayingPresenter.kt:157-187`）。

## Requirements

### R1. 封面取色

- 从真实封面位图提取适合作为播放器背景的种子色，综合颜色人口、饱和度和明度，避免只按最高像素计数选择低信息背景色。
- 优先选择能够代表封面主体且适合深色电视界面的色彩档案；无合适彩色档案时使用封面中稳定的中性色，不再根据歌名生成与封面无关的随机色。
- 将种子色映射为受控的深色背景，保证现有白色文字、歌词和控件仍清晰可读。
- 取色和位图解码不得阻塞 Compose 主线程；切歌时保留现有背景并平滑过渡到新背景。

### R2. 文本对齐

- “退出漫游”文字在按钮可见边界内水平、垂直居中，聚焦/按下/缩放时不偏移。
- 播放队列的序号、歌名/歌手和“正在播放”状态在每一行内形成稳定的垂直居中布局；中文字体的行高不再使内容整体上浮或下沉。
- 队列重试按钮的文字也遵循同一居中约束。
- 不改变现有 D-pad 焦点图、语义描述或点击行为。

### R3. 歌单和歌手加载保持

- 首页歌单、全部歌单、“我的音乐”歌手与全部歌手复用当前登录会话内的已加载数据。
- 从详情页返回或在上述入口间切换时，已有内容立即可见，不先清空再加载。
- 同一份初始数据未失效时不得重复请求第一页；分页、错误重试和焦点恢复保持现有行为。
- 专辑入口使用相同的现有数据保持机制，因为它与歌手位于同一加载链路，避免同类空白继续存在。
- 退出登录或切换账号后不得复用上一账号的数据。

### R4. 无空白切歌过渡

- 播放身份和播放控制立即跟随真实当前歌曲。
- 新封面仍在加载时继续显示上一张已解码封面和上一背景；新封面就绪后一次替换并沿用现有颜色动画。
- 新歌词仍在加载时继续显示上一份可显示歌词，不展示短暂的“歌词加载中”或“暂无歌词”；新歌词到达、确认无歌词或失败后再切换到对应终态。
- 首次进入播放器且没有任何历史可显示资源时，仍允许显示现有加载/缺省状态。
- 旧请求的迟到结果不得覆盖当前歌曲的新资源，现有身份和 revision 防护保持有效。

## Acceptance Criteria

- [x] AC1: 对粉/紫主体、蓝/紫主体、黑边占比高、低饱和封面分别验证，生成背景与封面可观察主色同色相或为其受控中性色，不出现由标题哈希产生的无关黄绿/紫色。
- [x] AC2: 所有生成背景保持深色，播放器主要文字和当前歌词维持可读对比度。
- [x] AC3: “退出漫游”、正常队列行、当前歌曲队列行和队列重试按钮的内容均在固定边界内居中，焦点缩放不引发布局跳动。
- [x] AC4: 返回首页/全部歌单/我的音乐/全部歌手/全部专辑时，先前加载的数据在首帧可见，且不会重复请求已保留的第一页。
- [x] AC5: 切换下一首时，封面区域不会出现字母占位图，歌词区域不会闪现加载或暂无歌词文案；新资源终态到达后正确替换。
- [x] AC6: 首次播放、无封面、无歌词和资源失败仍有明确稳定的现有终态，不会无限保留上一首内容。
- [x] AC7: A -> B -> A 且请求逆序完成时，只能显示最新 A revision 的新资源；队列焦点和漫游焦点测试继续通过。
- [x] AC8: 相关单元测试、Compose UI 测试、lint 和构建通过。

## Out of Scope

- 复制或声称还原网易云音乐 TV 的私有源码算法。
- 改变播放器整体版式、字体家族、歌词滚动规则或遥控器焦点顺序。
- 将歌单、歌手页面数据新增为跨启动或跨账号的持久缓存。
- 改变服务端 API、播放队列协议或音频切换行为。

## Technical Notes

- 以 Android 官方 Palette 的目标色/色板评分思路为实现基线；最终选择规则必须有确定性测试，不能直接依赖标题哈希。
- 会话级列表保持复用现有 `LibraryRetainedStateStore`，不引入新的持久化层。
- 切歌保持应位于 UI 展示投影/解码边界，不能放宽 presenter 对旧 revision 结果的拒绝规则。
