# 播放页海报模式与进度条实施计划

## Implementation

- [ ] 提取播放器布局所需的封面 ID、歌词窗口和进度比例等稳定派生值。
- [ ] 将 `ImmersivePlayer` 根布局改为内容层加底部控制覆盖层，确保控件显隐不触发布局位移。
- [ ] 实现大海报左右分栏布局，复用图片、标题和歌词组件。
- [ ] 将原封面模式改为 CD 模式：原创同心盘面、圆形封面盘芯、原创简化静态唱臂、播放旋转/暂停静止，并保持旧偏好值兼容。
- [ ] 实现固定高度的歌词上下文与当前行视觉层级，覆盖双语、静态、加载、失败和空状态。
- [ ] 调整长歌词排版：当前组 4 行自然换行、邻近组 2 行，总高度不变且当前组不显示省略号。
- [ ] 实现网易云调研风格的全宽细进度条、圆形进度点、左右时间和居中控制区。
- [ ] 补齐进度条与传输按钮的显式上下左右焦点路由，保持隐藏态首键、Back 和漫游逻辑。
- [ ] 添加针对歌词窗口、进度比例或可独立验证焦点状态的测试；更新现有 TV 交互测试或新增播放器设备测试。
- [ ] 按 HTML 分拆并实现 `PlaylistTile`、`ArtistLockup`、`AlbumLockup`：对应上图下文、圆形头像横向块、方形封面横向块，替换首页/我的/全部列表/歌手详情中的通用胶囊卡。
- [ ] 复用当前封面位图提取并约束主色，完成播放器氛围渐变、歌词暗色保护层、切歌颜色过渡和稳定无图备用色。

## Validation

- [ ] `./gradlew :app:testSideloadDebugUnitTest`
- [ ] `./gradlew :app:assembleSideloadDebug`
- [ ] `./gradlew :app:lintSideloadDebug`
- [ ] 检查 `adb devices`；若有可用 TV 目标，安装 Debug APK 并在 1920x1080 采集大海报静止态、控制态和进度条焦点态截图。
- [ ] 手动走查：隐藏控制 -> 方向键唤起 -> Up 聚焦进度 -> Left/Right seek -> Down -> 上一首/播放/下一首 -> Back 隐藏 -> Back 退出。
- [ ] 手动走查普通队列边界、漫游无上一首/下一首、退出漫游、无封面、无歌词、长歌名、双语歌词，以及 CD 播放/暂停旋转状态。
- [ ] 手动走查深色、浅色、高饱和封面和无封面时的背景氛围与歌词对比，并确认切歌不闪白。
- [ ] 在 TV AVD 复验首页卡片媒体区，以及隐藏控制 -> 方向键唤起和进度条左右 seek 的真实按键链路。

## Review Gates

- [ ] 核对 `android-tv-interaction.md` 的隐藏态首键、焦点图、10 秒 seek 和 Back 契约。
- [ ] 核对没有新增网络请求、数据库迁移或播放队列重建。
- [ ] 核对 UI 没有复制网易云品牌资产或专有几何造型；CD 盘面与简化静态唱臂均为原创绘制。
- [ ] 核对工作区中用户已有的 Trellis journal 改动未被覆盖。

## Rollback

- 若新布局无法在 1080p 保持稳定，回退播放器组件区并保留纯函数测试；不触碰播放服务、缓存或偏好数据。
