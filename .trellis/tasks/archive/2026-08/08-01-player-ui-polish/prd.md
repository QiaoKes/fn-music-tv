# 优化播放页海报模式与进度条交互

## Goal

把现有电视端播放页优化为适合客厅远距离观看和遥控器操作的沉浸式播放器：大海报模式采用用户本次参考图中的左右分栏构图；另一种布局改为上个任务网易云音乐 TV 截图所示的 CD/唱片构图；歌词成为右侧主视觉，控制层采用调研中确认的细线、全宽、按需显示样式，同时保持播放、漫游和歌词数据行为不变。

## Background

- 当前播放器位于 `AuthenticatedApp.kt:633`，大海报模式只把方形图片从 `390dp` 放大到 `420dp`，没有形成参考图中的近半屏视觉。
- 当前进度条位于右侧内容列中，轨道较粗并用边框表达焦点；此前调研确认的参考样式是底部全宽细线、左右时间端点、中央传输控制，并且控制层显示时不替换歌词。
- 既有产品约束要求页面默认安静、控制层临时显示、第一次方向键只负责唤起控制、返回键先关闭控制层、进度条聚焦后左右按键每次快进或快退 10 秒。
- 上个任务保留了 `tv-after-consent.png`、`tv-controls.png`、`tv-back.png` 和 `tv-left.png` 四张播放器参考图：静止态为左侧大尺寸唱片/CD 视觉与右侧歌词，控制态在底部叠加进度与传输操作。
- 大海报模式继续请求 `CoverVariant.Poster` 原图并沿用现有尺寸与像素安全限制；CD 模式使用现有播放器封面生成原创圆形盘芯、盘面和简化静态唱臂，不引入第三方视觉资产，也不复制网易云品牌元素或其唱臂细节。

## Requirements

### R1. 大海报模式布局

- 左侧图片区域约占屏幕宽度的 46%-50%，从安全区顶部延伸到底部，弱化卡片感和外层圆角，形成参考图中的大幅海报视觉。
- 图片保持原始比例，横图、竖图和方图都不得拉伸；优先完整、清晰显示，不用重度模糊或低清放大填充。
- 右侧顶部稳定显示歌名和歌手，下面显示同步歌词；歌曲信息、歌词和底部控制层不得因长文本互相挤压或遮挡。
- 当前歌词为主要阅读目标，使用高亮、大字号和较强字重；长句必须自然换行，当前组最多容纳 4 个视觉行，不得用省略号截断。前后歌词保留上下文并逐级降低对比度，双语歌词保持同一时间组内上下排列。
- 无封面时使用稳定的字母/文字占位，不生成伪海报。

### R2. CD 模式

- 将设置中现有“封面模式”改名为“CD 模式”，不改变已保存的底层枚举值，避免偏好迁移或老用户设置丢失；默认仍为大海报模式。
- 左侧显示接近半屏高度的大尺寸圆形 CD/唱片视觉，专辑封面裁成圆形盘芯并保持居中；盘面使用原创的同心纹理、边缘高光和克制层次，并叠加原创、简化的静态唱臂，不直接复刻网易云截图中的素材或专有造型。
- 播放时 CD/唱片低速、匀速旋转，暂停时停止；动画只作用于绘制层，不触发图片重新加载或主布局位移。
- CD 模式与大海报模式共用歌曲信息、歌词、底部控制层和播放状态，不重复网络请求或重建播放队列。
- 设置页选中两种模式时分别显示“CD 模式”和“大海报模式”，播放器页面内不出现模式切换入口或标签。

### R3. 网易云调研风格的进度与控制层

- 控制层作为底部悬浮层覆盖在主内容之上，不参与主布局测量；显示和隐藏时海报、歌曲信息和歌词不得跳动。
- 进度轨道横跨屏幕底部安全区，使用约 2-3dp 的细轨道、已播放高亮段和小型圆形进度点；焦点状态通过进度点/高亮增强表达，不使用粗边框包围整条轨道。
- 已播放时间和总时长分别贴近轨道左右端点，传输控制在下方居中；漫游状态保留明确的“退出漫游”动作。
- 页面进入后控制层短暂显示；无操作约 5 秒自动隐藏。方向键首次唤起控制后聚焦播放/暂停，返回键先隐藏控制层。

### R4. 遥控器与状态反馈

- 控制层显示后，向上可进入进度条；进度条聚焦时左右键按 10 秒步长 seek，向下回到播放/暂停。
- 上一首、播放/暂停、下一首和退出漫游使用显式焦点顺序；禁用的上一首/下一首不能成为焦点目标。
- 播放、歌词加载/失败、无歌词、队列错误和漫游单飞行为保持现状。
- 所有可聚焦控制在 1920x1080 下有清晰可见的焦点反馈，文字不越界、不遮挡。

### R5. 首页媒体卡片

- 歌单卡片沿用 HTML 原型 `playlist-card` 的上图下文结构、8px 级小圆角和约 `385x284px` 物理比例；媒体区约占 76%，真实封面铺满显示，随机漫游、全部歌单和缺图状态使用原创唱片/封套构图。
- “我的”页面不得再让歌手、专辑和歌单复用同一个纵向卡片。歌手采用 HTML `artist-lockup` 横向结构：约 `340x190px`，左侧约 `122px` 圆形头像，右侧姓名和歌曲数；专辑采用 HTML `album-lockup` 横向结构：约 `330x190px`，左侧约 `146px` 方形封面，右侧专辑名和歌手。
- 全部歌手、全部专辑以及歌手详情中的专辑入口继续使用对应的歌手/专辑组件，不回退为通用胶囊按钮。
- 所有媒体块保持 8px 级圆角和约 1.025 的轻微焦点放大；不得出现 TV Material 默认胶囊轮廓、文字裁切或焦点导致的布局跳动。

### R6. 封面驱动的播放器氛围背景

- 播放页背景颜色必须从当前歌曲封面派生，而不是使用固定主题色；主色需压暗并适度降低饱和度，从左侧封面区域向右侧歌词区域形成自然的深色层次。
- 歌词区域始终叠加稳定暗色保护层，不能因浅色、高饱和或近白封面降低文字可读性；切歌时颜色平滑过渡，不闪白、不引发布局位移。
- 复用播放器已经加载的封面位图提取颜色，不为背景额外发起图片网络请求，不增加实时模糊或持续位图处理。
- 无封面、加载失败和加载中的状态根据歌曲标题与歌手生成稳定的降饱和备用色，同一首歌曲每次进入保持一致。

## Out Of Scope

- 不新增收藏、音效、播放模式、队列编辑或音质选择功能。
- 不复制网易云的唱臂素材、品牌图标、精确配色或专有几何造型；CD/唱片主体与简化唱臂均使用本项目原创绘制。
- 不改动服务端接口、播放队列、缓存数据库、歌词解析规则或播放服务。
- 本任务不重做首页、登录页和设置页的整体结构；首页只优化现有卡片的媒体图片区域。

## Acceptance Criteria

- [ ] AC1: 在 1920x1080 大海报模式中，左侧视觉约占半屏且明显大于当前 `420dp` 方图，右侧完整显示歌曲信息和至少 3 组歌词上下文。
- [ ] AC2: 方形、横向和竖向图片均保持比例；无封面、图片加载中或解码失败时布局尺寸稳定。
- [ ] AC3: 当前歌词和邻近歌词层级清晰；当前长句/双语歌词自然换行且无省略号，最多 4 个视觉行仍位于预留空间内，不推动底部控制层，也不遮挡歌曲信息。
- [ ] AC4: 控制层显示时出现全宽细进度线、圆形进度点、左右时间和居中传输操作；隐藏后主内容位置不变化。
- [ ] AC5: 控制层隐藏时第一次方向键只显示控制；再次向上聚焦进度条后，左右键每次 seek 10 秒，向下返回播放/暂停。
- [ ] AC6: 返回键在控制层显示时只隐藏控制层；再次返回才离开播放器，播放继续。
- [ ] AC7: 普通队列和漫游模式的上一首、下一首、播放/暂停、退出漫游行为与现有逻辑一致，连续按键不会触发并发漫游请求。
- [ ] AC8: 设置页显示“CD 模式”和“大海报模式”；已保存的旧 `Cover` 偏好自动显示为 CD 模式，不需要数据库迁移。
- [ ] AC9: CD 模式左侧呈现大尺寸圆形盘面、圆形专辑盘芯和原创简化静态唱臂；播放时盘面平滑旋转、暂停时静止，切歌时更新封面但不重建播放器。
- [ ] AC10: 相关单元/设备测试、Debug APK 构建和 Android lint 通过；若本机存在可用 TV 模拟器或设备，完成 1920x1080 安装与截图验收。
- [ ] AC11: 歌单呈现 HTML 的上图下文卡片；歌手呈现圆形头像横向块；专辑呈现方形封面横向块。三者均为 8px 级圆角、轻微焦点放大，无胶囊轮廓、文字裁切或加载跳动。
- [ ] AC12: 播放页背景随当前封面呈现可辨识但克制的主色氛围，歌词侧保持深色和清晰对比；切歌平滑过渡，无封面时备用色稳定，且没有重复封面请求。
