# TV 音乐客户端 V1 方案

## Goal

为现有 NAS 音乐服务设计一个适合电视遥控器操作的原生大屏客户端 V1，让用户能以低学习成本完成登录、浏览歌单、播放歌曲、进入沉浸式大屏播放、使用漫游模式并查看同步歌词。

本任务先交付可进入开发的完整产品与实现方案，不在规划评审通过前修改产品代码。

## Background And Confirmed Facts

- 服务端已有可用的 Web 前端：`http://10.0.0.115:5666/music/`，当前浏览器已有登录态，可用于核对真实数据结构与现有能力。
- 服务端 API 文档位于 `docs/API.md`。
- 已核对正确的网易云音乐 TV 安装包 `com.netease.cloudmusic.tv`；此前 `.detail/` 的
  手机版 APK 已排除，不作为任何设计依据。
- 首发目标设备已确定为 Android 系统的 Vidda C3 Pro 投影仪（官方型号 `VL7R-PRO`，
  MT9681、4 GB/128 GB、4K）；具体 Android API、ABI 和实际应用渲染分辨率仍需实机读取。
- UI 只借鉴成熟 TV 音乐产品的交互原则与视觉气质，不进行网易云音乐 UI 的 1:1 复制。
- V1 仅覆盖基础登录、歌单播放、歌曲播放、大屏播放、漫游模式和歌词。

### Scope Decision D1: 我的资料库下钻

本方案建议把“歌手 / 专辑 / 全部歌曲”纳入 V1 的**只读下钻与播放**，不含编辑、收藏或
管理。理由是 TV 上可聚焦的媒体内容带应有明确确认动作，不能成为假入口。本次方案评审
若通过，即视为确认 D1；若不确认，三条内容带只保留不可聚焦的概览，移除相应详情页、
分页与播放来源，预计减少 3-5 个工程日。评审完成前，D1 不作为已确认验收门槛。

## Requirements

### Product Scope

- 提供适配电视遥控器的 NAS 地址、账号、密码输入登录流程，文本输入调用系统电视键盘；
  密码行带可聚焦的显示/隐藏按钮。
- 登录页默认预填最近一次有效的 NAS 主机/端口/路径，地址尾部可打开本机最近服务器记录；
  HTTPS 使用独立开关控制协议，当前 HTTP NAS 默认关闭并显示未加密提示。
- 提供默认开启的“保持登录”：只将用户 token 写入 Android Keystore；关闭时 token 仅保留
  在当前进程。两种状态都绝不保存密码。
- V1 不提供二维码、手机扫码、第三方授权、忘记密码或局域网服务器发现。
- 登录后的一级导航只保留“首页”和“我的”，不复制参考产品的多频道结构。
- 左上角提供稳定的“正在播放”回入口；已有播放上下文时展示封面、歌名和歌手，确认后返回大屏播放页。
- 首页参考网易云音乐 TV 首页的空间组织与遥控器浏览节奏，提供随机漫游入口和歌单内容；
  不复制其品牌、频道、文案或内容布局。
- 首页歌单预览提供“全部歌单”任务页，确保所有可访问歌单都能进入；该页不是一级导航。
- “我的”页面承载账号状态、歌手、专辑、音乐库概览和设置，不重复首页的歌单内容。
- 按 D1 推荐范围，“我的”的歌手和专辑内容可进入只读列表/详情，并从详情播放全部或
  单曲；“音乐库”提供全部歌曲入口和共享库可用状态。V1 不提供这些对象的编辑或管理。
- 展示用户可访问的歌单，并支持进入歌单查看歌曲列表。
- 支持从歌单播放全部歌曲或选择单曲开始播放。
- 点击歌曲后进入沉浸式大屏播放模式。
- 大屏播放提供“封面模式”和“大海报模式”两种视觉布局：前者使用克制的封面主视觉，后者用左侧大幅清晰封面/海报配右侧歌曲信息与同步歌词。
- 用户只能在“我的 → 设置 → 播放界面”切换默认布局；首次安装默认为大海报模式，
  设置在电视本地持久化。
- “我的 → 设置”提供音频与图片缓存上限，默认 512 MB，可选 128/256/512/1024 MB，
  默认按音频 75% / 图片 25% 分配。资料索引属于应用数据而非播放缓存，最多另占 32 MB，
  必须在设置副文案中明确披露。
- 播放页不展示布局切换入口或模式标签；播放控制仅在遥控器交互时临时浮现。
- 支持基础播放控制和播放状态展示。
- 在首页、我的和歌单之间浏览时持续播放；冷启动可恢复本地队列但保持暂停，不自动发声。
- 支持漫游模式，在缺少明确点播目标时连续提供可播放内容。
- V1 的漫游按现有服务端能力定义为随机漫游，不宣传个性化推荐。
- 支持与当前播放进度同步的歌词展示。
- 所有核心操作均可通过方向键、确认键和返回键完成，并提供清晰、稳定的焦点反馈。

### Planning Deliverables

- 基于真实 Web 前端、API 文档和 APK 样本形成调研结论。
- 给出 V1 信息架构、页面与状态清单、主要遥控器交互路径及 UI 设计稿。
- 给出客户端架构选型、模块边界、关键数据流、播放方案和服务端 API 映射。
- 给出电视端启动、列表、图片、网络、音频播放、歌词和内存方面的性能预算及优化策略。
- 给出分阶段实现清单、验证方法、风险、兼容策略和明确的 V1 外延边界。

## Out Of Scope

- 搜索、收藏管理、歌单增删改、下载与离线播放。
- 评论、社交、视频、播客、电台、有声书和直播。
- 均衡器、音效、跨设备续播、投屏、桌面歌词和复杂播放队列编辑。
- 除播放界面样式和缓存上限外的复杂个性化设置。
- 歌手、专辑、歌曲和音乐库的新增、编辑、删除、扫描与路径管理。
- 账户注册、找回密码、会员或付费能力。
- mDNS/SSDP 等局域网服务器自动发现。
- 对网易云音乐品牌元素、布局或视觉资产的直接复制。

## Acceptance Criteria

- [ ] 用户可仅用遥控器和系统电视键盘输入 NAS 地址、账号和密码完成登录；最近服务器、
  密码可见、保持登录、HTTPS 开关都可达，且没有扫码、忘记密码或局域网发现假入口。
  粘贴 HTTP/HTTPS 地址会同步安全开关，其他 scheme 或内嵌账号密码的 URL 会被拒绝。
- [ ] 用户可编辑 NAS 地址；密码不落盘，用户 token 过期与 HLS/漫游 session 失效采用不同恢复路径。
- [ ] 登录后一级导航仅有“首页”和“我的”；用户能从任一一级页面聚焦左上角正在播放入口并返回大屏播放页。
- [ ] 首页能直接启动随机漫游，并通过预览或“全部歌单”进入任意可访问歌单；“我的”展示账号、歌手、专辑、音乐库概览和设置，
  不重复展示歌单网格。
- [ ] “我的”采用 TV 内容带而不是三列桌面仪表盘，共享音乐库只展示名称与可用状态且
  不泄露 NAS 路径；本次评审确认 D1 后，歌手/专辑可进入只读详情并播放，“全部歌曲”
  可分页浏览。
- [ ] 用户可进入歌单、浏览歌曲，并通过“播放全部”或选中歌曲开始连续播放。
- [ ] 大型歌单按页加载并增量建立队列；CUE 分轨不走会播放整文件的 direct stream。
- [ ] 选中歌曲播放后进入大屏播放页，能看到歌曲信息、封面、播放状态和可操作的基础控制。
- [ ] 首次播放默认进入大海报模式；用户只能在“我的 → 设置”切换封面/大海报布局，
  播放页内没有切换入口，重启应用后仍保持选择。
- [ ] “我的 → 设置”可配置音频与图片缓存上限，默认 512 MB，可选 128/256/512/1024 MB；
  可查看当前使用量并清除缓存，操作不打断当前播放；V1 不提供可管理、可保证或固定保留的
  离线入口。资料索引作为应用数据最多另占 32 MB，界面不得把 512 MB 描述为整个应用占用。
- [ ] 大海报模式优先完整、清晰地显示服务端封面，不通过拉伸或重度模糊填充画面；无封面时有稳定占位视觉。
- [ ] 大屏播放页能显示与播放进度同步的歌词；空列表统一显示“纯音乐或暂无歌词”，
  并与加载中、网络失败状态区分。
- [ ] 漫游模式能从约定入口启动并持续衔接内容，退出后不会破坏普通歌单播放上下文。
- [ ] 核心页面的焦点路径无死角，快速连续按键不会造成焦点丢失、重复打开页面或明显卡顿。
- [ ] 方案文档包含完整页面设计、关键状态、交互说明、架构、API 映射、性能预算、测试策略和实施计划。
- [ ] 后台/页面切换不中断播放；冷启动恢复后默认暂停，避免电视自行出声。

## Planning Assumptions Pending User Confirmation

- 客户端暂按 Android 6.0（API 23）及以上设计；Vidda C3 Pro 是首发实机门槛，2 GB/1080p
  TV AVD/盒子仅作兼容回归。最终 minSdk 以该投影仪 About/ADB 实测为准。
- 首版登录页可编辑 NAS 地址；如果产品只绑定一台预置 NAS，可在实现时隐藏该字段。
- 本地恢复普通播放队列与位置，但不承诺跨设备同步；随机漫游 session 失效时重新开始。
- D1 是否随本方案一起确认；推荐确认只读浏览/播放，共享音乐库仍只做状态概览。
